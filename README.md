# Prediction Market Comment Analysis

This project processes, analyzes, and classifies public comments and attachments related to prediction markets, focusing on identifying and quantifying references to gambling, economic theory, and insider trading. It leverages NLP techniques (tokenization, lemmatization, word counting) and machine learning model outputs for classification.

## File and Directory Descriptions

### Python Source Files

- **classify_pro_against.py**  
  Classifies comments as "PRO", "AGAINST", "UNCLEAR", or "NO COMMENT" using a language model.  
  - **main**: Loads comments, applies classification, and manages output.
  - **get_model**: Loads the specified ML model for classification.

- **classify_pro_against_majority.py**  
  Aggregates multiple model outputs to determine the majority classification for each comment.
  - **main**: Loads model outputs, determines majority class, and updates the dataset.

- **count_words.py**  
  Main script for NLP processing, word counting, and CSV generation.  
  **Key functions:**
  - **lemmatize, lemmatize_word_list, lemmatize_text**: Load spaCy model and lemmatize text/word lists.
  - **proccess_word_list**: Lowercases, expands, and lemmatizes word lists.
  - **get_words_lists_gpt, get_words_lists_claude, get_weighted_words_lists**: Load and process word lists from CSVs.
  - **tokenize_and_save_attachments**: Tokenizes raw text files and saves tokens.
  - **lemmatize_tok_files**: Lemmatizes tokenized files and saves lemmas.
  - **count_words**: Counts occurrences of target words/phrases in a list.
  - **process_comments_csv**: Processes comments and attachments, counts/ratios for word categories, and saves results.
  - **proccess_comments_inside_trading**: Processes comments for inside trading word categories.
  - **words_lemWords_dict**: Maps lemmatized words to original forms.
  - **count_inside_trading_words**: Counts specific inside trading words in comments.
  - **count_gambeling_economic_words**: Counts gambling/economic words in comments.
  - **compare_gemma_output_with_comments_processed_inside_trading_count**: Compares model output with inside trading word counts.
  - **compare_gemma_output_with_comments_processed_gambling_economic_count**: Compares model output with gambling/economic word counts.
  - **proccess_comments_with_weights**: Processes comments using weighted word lists.
  - **handle_missed_comments, fill_missed_comments, fill_missed_comments_all**: Handle and merge missed comments into main datasets.

- **DIR_CONST.py**  
  Defines directory constants for use throughout the project.

- **Get_PDF_text.py**  
  Extracts text from PDF and DOCX files in the raw folder, skipping files already processed.

## Functionality Overview

### NLP Processing and Word Counting

- **Tokenization & Lemmatization**:  
  Attachments are tokenized and lemmatized using spaCy for consistent word matching.

- **Word List Management**:  
  Word lists for gambling, economic, ambiguous, and inside trading terms are loaded, expanded (hyphen handling), and lemmatized.

- **Comment Processing**:  
  Each comment and its attachment (if present) are processed to count and calculate the ratio of target words. Results are saved to CSV.

- **Weighted Scoring**:  
  Some analyses use weighted word lists to compute a weighted score for each comment.

### Classification

- **Model-Based Classification**:  
  Comments are classified as "PRO", "AGAINST", etc., using ML models (Gemma, Llama3).

- **Majority Aggregation**:  
  Multiple model outputs are aggregated to determine the majority class for each comment.

### Comparison and Analysis

- **Comparison Scripts**:  
  Compare model outputs with word count results to analyze the relationship between language and classification.

- **Missed Comments Handling**:  
  Special handling for comments missed during initial processing, ensuring all data is eventually analyzed and merged.

## How to Use

1. **Extract Text**:  
   Use Get_PDF_text.py to extract text from PDFs/DOCX files.

2. **Tokenize & Lemmatize**:  
   Run tokenization and lemmatization functions in count_words.py to prepare attachment data.

3. **Process Comments**:  
   Use `process_comments_csv` and related functions to analyze comments and attachments for target word categories.

4. **Classify Comments**:  
   Use classify_pro_against.py and classify_pro_against_majority.py to classify comments.

5. **Compare Results**:  
   Use comparison functions in count_words.py to relate model outputs to word count analyses.

6. **Handle Missed Comments**:  
   Use `handle_missed_comments` and `fill_missed_comments_all` to ensure all comments are processed.
